# 水理ラボ

水槽に障害物と水源を配置し、水の流れを 3D で計算して表示するブラウザ用のシミュレータです。

`index.html` をそのままブラウザで開けば動きます（WebGPU が必要です。最新の Chrome、Edge、Safari、Firefox）。

## できること

- 障害物: 箱、板、球、円柱、円錐、ドーナツ、コップ、容器、樋。位置・回転・寸法・素材を自由に設定
- 水源: 蛇口（水量と勢い）、水滴（粒の直径と間隔）、シャワー（広がり角）、まとめて（一度に出す量・繰り返し）、雨（雨量と範囲）。向きと総量も指定可能
- 水の塊（最初から張っておく水）、排水口
- 再生・一時停止・コマ送り・スロー再生（1/4、1/10、1/40）、最初の状態に戻す
- 編集: 3D ビュー上の矢印・輪・つまみ、Blender と同じ G / R / S / X / Shift+A / Shift+D、元に戻す・やり直し

## しくみ

- 水の本体: GPU 上の FLIP 法（MAC 格子、圧力はレッドブラック SOR、障害物は面ごとの開口率で表現）
- 細かい波紋: 毛細管重力波の分散関係を厳密に解くスペクトル法（水槽の壁で反射、障害物の位置で吸収）
- 描画: 粒子からの画面空間液体表面、上から見た水面高さによる水底の集光模様、白い泡としぶき、影、ブルーム

## ソース

`src/shell.html` と `src/js/*.js` を `node build.mjs` で 1 つの `index.html` にまとめています。
