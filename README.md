# 水理ラボ

水槽に障害物と水源を配置し、水の流れを 3D で計算して表示するブラウザ用のシミュレータです。

`index.html` をそのままブラウザで開けば動きます（WebGPU が必要です。最新の Chrome、Edge、Safari、Firefox）。

## できること

- 物体: 箱、板、球、円柱、円錐、ドーナツ、コップ、容器、樋。位置・回転・寸法・素材・色を設定
- 水源: 蛇口（流量・勢い・出口の太さ）、水滴（粒の直径と間隔）、シャワー（広がり角）、まとめて（一度に出す量と繰り返し）、雨（雨の強さと範囲）。向きと総量も指定
- 水の塊（置いた所にすぐ水が入り、最初の状態に戻したときもその形で入る）、排水口
- 再生・一時停止・コマ送り・スロー再生（1/4、1/10、1/40）、水を最初の状態に戻す
- 編集: 3D ビュー上の矢印・輪・つまみ。Blender と同じ軸（Z が上）とキー操作（G / R / S と X・Y・Z での軸固定、数値入力、Shift+A、Shift+D、X / Delete、1・3・7・Home・.）、元に戻す・やり直し
- ファイル: 新規、JSON への保存と読み込み、サンプル 6 種。作業中のシーンはブラウザに自動で残ります
- スマートフォン: 1 本指で視点、2 本指で拡大と平行移動、選んだ物の設定は画面下のシートに表示

## しくみ

- 水の本体: GPU 上の FLIP 法（MAC 格子、圧力はレッドブラック SOR、障害物は面ごとの開口率で表現）
- 格子より小さい水滴: 水面に落ちると液体に合流し、運ぶ運動量を波紋の層への圧力の衝撃と、飛び散る水しぶき（はね上がりの強さは We·Oh^-0.4 で判定）に変える
- 細かい波紋: 毛細管重力波の分散関係を厳密に解くスペクトル法（水槽の壁で反射、障害物の位置で吸収）
- 描画: 粒子からの画面空間液体表面、上から見た水面高さによる水底の集光模様、白い泡としぶき、影、ブルーム

## ソース

`src/shell.html` と `src/js/*.js` を `node build.mjs` で 1 つの `index.html` にまとめています。
