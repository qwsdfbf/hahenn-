# 水理ラボ（Blender アドオン）

Web 版の水理ラボと同じ計算で、Blender の中に置いた水槽に水を流すアドオンです。
レンダリングは Blender の標準機能（Cycles / EEVEE、レンダーパス、モーションブラー、ビューレイヤー、コンポジット）でそのまま行えます。

## 入れ方

1. `suiri_lab.zip` をダウンロードします。
2. Blender（4.0 以降）で「編集 > プリファレンス > アドオン」を開き、「インストール…」（4.2 以降は右上の ∨ から「ディスクからインストール…」）で zip を選びます。
3. 「水理ラボ」にチェックを入れます。
4. 3D ビューのサイドバー（N キー）に「水理ラボ」タブが出ます。

## 使い方

1. 「水槽を作る」か、サンプル（蛇口とコップ・樋を流れる水・ダムの決壊・水滴と波紋・噴水・雨）を置きます。
2. 「追加」から水源・物・水の塊・排水口を置きます。自分で作ったメッシュも「障害物にする」で計算に入ります。
3. 水源を選ぶと、出し方（蛇口・水滴・シャワー・まとめて・雨）と量・勢いを決められます。水は水源の -Z の向きに出ます（R キーで回すと向きが変わります）。
4. 「計算する」でシーンの開始〜終了フレームを計算します（Esc で途中で止められます）。結果は .blend の隣の `suiri_cache` に保存され、再生・レンダリングで読み込まれます。
5. 水の中に沈む自分の物には「水中の光を素材に入れる」で集光模様と水の色の吸収を入れられます。

キーフレームで動かした物や水源（位置・向き・流量・水を出すかどうか）も、そのまま計算に入ります。

## 独自の部分と Blender 標準の部分

- 独自（Web 版から移植）
  - 水の計算：FLIP 法（MAC 格子、開口率による障害物、レッドブラック SOR）、格子より小さい水滴の着水と水しぶき（We·Oh^-0.4）、白い泡としぶき
  - 水を出す仕組み：蛇口・水滴・シャワー・まとめて・雨・水の塊・排水口
  - 細かい波紋：毛細管重力波の分散関係を厳密に解くスペクトル法
  - 水の質感：波紋の傾きによる水面の法線、水底の集光模様、水の色の吸収（素材のノードとして入ります）
- Blender 標準
  - 水面は普通のメッシュ（速度属性付きでモーションブラー・Vector パスに対応）、泡としぶきはジオメトリノードのインスタンス
  - 素材は Principled BSDF などの標準ノードで、自由に編集できます
  - 照明（太陽ライトの向きが集光模様に使われます）、カメラ、レンダーパス、コンポジットはすべて Blender のもの

## 計算の重さ

1 フレームの計算時間の目安（水深 5 cm・60×40 cm の水槽）：低 約 0.5〜1 秒、標準 約 2 秒、高 約 5 秒以上。
